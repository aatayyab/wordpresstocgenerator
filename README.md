# Universal WordPress Table of Contents & Archive Generator

A zero-dependency, browser-based utility that instantly crawls any public WordPress.com blog via API, grouping every published post chronologically into clean HTML archives for effortless site organization.

🌐 **Live Demo & App:** [https://aatayyab.github.io/wordpresstocgenerator/](https://aatayyab.github.io/wordpresstocgenerator/)

---

## Key Features

- **Universal Domain Crawler:** Input any public WordPress.com blog subdomain or custom domain to generate a complete post inventory.
- **Pagination Bypass:** Automatically crawls through massive blogs in batches of 100 to ensure zero missed articles.
- **Chronological Grouping:** Organizes posts neatly by year and date in descending order for optimal readability.
- **Gutenberg-Ready Output:** Formats results instantly into native WordPress Custom HTML blocks ready for one-click copying.

---

## How to Use

1. Open the live tool on GitHub Pages ([Launch App](https://aatayyab.github.io/wordpresstocgenerator/app.html)).
2. Enter your target WordPress.com blog domain (e.g., `aatayyab.wordpress.com`).
3. Click **Build TOC** to crawl and compile all posts.
4. Click **Copy HTML to Clipboard** and paste directly into a WordPress Custom HTML block.

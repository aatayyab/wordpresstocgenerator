    Enter Target Domain

Usage Guide

Adding Archives to WordPress

1. Open Web Tool

Navigate to the browser tool page and input the site address.

2. Run Crawler

Allow the crawler to cycle through pagination pages until all entries are fetched.

3. Copy Output

Click the Copy HTML to Clipboard button to retain the Gutenberg markup.

4. Paste into Editor

In your WordPress post or page editor, add a Custom HTML block and paste the content.
